# j4xstores

This repository contains a minimal Next.js (App Router) scaffold with a ChatSlide widget that opens a chat iframe.

To run locally:

1. pnpm install (or npm install)
2. pnpm dev (or npm run dev)

The ChatSlide iframe points to https://dinaaicom.vercel.app by default. Change components/ChatSlide.tsx to update the iframe src.
